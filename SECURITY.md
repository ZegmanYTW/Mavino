# Security Policy

## Supported Versions

The following versions of Mavino are currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| Older versions | :x: |

Only the latest release of Mavino receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Mavino, please report it through:

- [GitHub Issues](https://github.com/ZegmanYTW/Mavino/issues)

When reporting a vulnerability, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Screenshots or logs, if applicable.

### Response Time

You can expect an initial response within 7 days.

If the vulnerability is confirmed, we will work on a fix and release an update as soon as possible.

Please do not publicly disclose security vulnerabilities before they have been reviewed.

Thank you for helping keep Mavino secure! 💜

# Contributing to Mavino

Thank you for your interest in contributing to Mavino!

We welcome contributions, ideas, bug reports, and improvements that help make Mavino better.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes to ensure everything works correctly.
5. Submit a Pull Request with a clear description of your changes.

## Reporting Bugs

If you find a bug, please open a GitHub Issue and include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Screenshots or logs, if applicable.

## Suggesting Features

Have an idea for Mavino? Open a GitHub Issue and describe your suggestion, including how it could improve the application.

## Code Guidelines

- Keep the code clean and readable.
- Follow the existing project structure.
- Avoid unnecessary changes.
- Test your code before submitting a Pull Request.

  🎵 Mavino

A modern local music player for Windows.

Mavino is a desktop music player designed to make listening to your local music library simple, comfortable, and enjoyable.

✨ Features

- 🎧 Play local music files
- 📂 Browse your music library
- 🎨 Clean and modern interface
- ⚡ Simple and convenient controls

## 🛠️ Built With

- C#
- .NET
- WPF

## 📥 Installation

1. Go to the [Releases](../../releases) page.
2. Download the latest version.
3. Extract the files.
4. Launch `Mavino.exe`.

## 📌 Project Status

Mavino is currently under development. New features and improvements are coming.
